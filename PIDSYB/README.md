# PIDSYB 旋转倒立摆控制器（FPGA）

角度环 **PD** + 位置环 **PID** 的双环方案，带**能量泵 / 甩杆起摆**、固件内建运动曲线、
α-β 滤波、MP34DT01 麦克风单频检测和手轮（摇杆）模式。纯 Verilog-2001。

> 本文件是整理版速查说明。
> **完整原始说明书（59 KB，含全部调试过程、参数推导、踩坑记录）见 [`README_original.md`](README_original.md)** ——
> 遇到具体调试问题优先查那份。

| 项目 | 值 |
|---|---|
| 器件 | GW2A-LV55PG484C8/I7（GW2A-55C） |
| 时钟 | 50 MHz |
| 控制周期 | **5 ms**（角度环 / 状态机 / PWM），位置环 **25 ms** |
| 遥测 | **115200 8N1，102 字节 / 20 ms** |
| PWM 载波 | 5400（≈9.26 kHz），`PWM_MAX = 5300` |
| 资源 | 6114 Logic (12%)、3573 Register (9%)、**13 / 20 DSP (65%)** |
| 时序 | ⚠ **239 个 setup 违例，TNS −1331 ns**，最差 slack −9.56 ns（功能可用，未修） |

## 1. 控制结构

```
ang_err  = (angle − angle_mid) × ANGLE_INV
ang_d5   = ang_err − ang_err_5ms_ago          // 5 ms 差分

bal_pwm  = −( BAL_KP·ang_err + BAL_KD·v̂ )     // v̂ 来自 α-β 滤波器，不是裸差分

pos_err  = enc_rel − pos_target
pos_filt = pos_filt − pos_filt/8 + pos_err/8  // 一阶低通 1/8
pos_pwm  = clamp(POS_KP·pos_filt + POS_KD·pos_vel, ±PWM_MAX/2)

pwm_cmd  = clamp(bal_pwm − pos_pwm, ±PWM_MAX)
```

**为什么角度环禁止加 I**：摆杆稍偏就必须加速摆臂才能拉回。角度环若带积分，
会把「长期偏一点」当成要消掉的误差持续给摆臂加速，而摆臂加速又改角度 →
摆臂越跑越快 / 低频大摆。机械上摆杆竖直、摆臂不加速时力矩为 0，稳态误差本就该是 0。

**为什么位置环需要 I**：摆臂有静摩擦、电机死区、机械偏心，纯 PD 会停在
`误差 × POS_KP = 摩擦所需力矩` 处，永远回不到零位。
（当前 `POS_KI = 0`，因为积分会引起粘滑极限环，改用别的办法抑制。）

## 2. ⭐ 角度标度（最容易踩的坑）

实测：摆杆从竖直转到下垂，**180° 只跨越 534 个 ADC 计数**（旧版误用 3003）。

| 指标 | 旧标度 | 新标度 | 变化 |
|---|---|---|---|
| 计数 / 度 | 16.68 | **2.967** | ÷5.62 |
| 度 / 计数 | 0.060 | **0.337** | ×5.62 |
| ADC 1 LSB（4 计数） | 0.240° | **1.348°** | ×5.62 |

**两类参数必须朝相反方向缩放**，`top.v` 用 `SPAN_CNT_180` 统一处理：

| 类型 | 换算 | 例子 |
|---|---|---|
| **增益型**（计数 → PWM） | `new = old × span_old/span_new` | `BAL_KP` 35 → **120**（现场另调） |
| **阈值型**（与计数比较） | `new = old × span_new/span_old` | `ANGLE_LIMIT` 800 → **142** |
| **编码器域**（与角度传感器无关） | 不变 | `POS_*` / `FLING_*` / `ENC_JUMP_MAX` |

> 换电位器或传动比后，**只改 `SPAN_CNT_180` 一个数字**，所有角度域参数自动重算。

### 换标度后必须做的事

1. **重新标定平衡点**（`ZHONGZHI_DEF` 会失效）：
   网页「⭐ 当前设为平衡点」按钮，或把摆杆扶竖直后**按住 B3_SW1**
2. `ANG_RAIL_EN` 已关闭 —— 削顶判倾倒在新标度下会把「正常下垂」误判为「已倾倒」

## 3. α-β 滤波器

`src/alpha_beta.v`，同时估计角度和角速度，替代裸差分的 D 项。

| 项目 | 值 |
|---|---|
| 内部格式 | Q8 定点 |
| 输出 | **必须寄存器输出**（组合输出会串进两级乘法，TNS 恶化到 −2425） |
| `α`（`0x1B`） | **153**（Q8 = 0.598） |
| `β`（`0x1C`） | **65**（Q8 = 0.254，满足 β = α²/(512−α)） |
| 限幅 | ±2²²（早期 ±2¹⁹ 太小，上电收敛慢） |

实测效果：

| 量 | 滤波前 σ | 滤波后 σ | 改善 |
|---|---|---|---|
| 位置 | 22 | 8.63 | 2.6× |
| 速度 | 30.88 | **0.90** | **34×** |

**为什么用这么快的滤波**：实测摆动周期约 240 ms（**4 Hz**）。
α=51/β=6 在 4 Hz 处速度滞后 66° → D 项变负阻尼；
改成 **α=153/β=65** 后 4 Hz 滞后仅 13.5°。噪声小（σ 0.4 计数），可以放心用快滤波器。

> ⚠ **量化限制**：α-β 的速度输出是整数「计数/拍」= **67°/s 一个台阶**。
> 所以 `BAL_KD` 不要超过 ~800，否则 D 项变成阶梯跳动。

只作用于 `S_BALANCE`；削顶检测改用原始 `angle` 而非 `angle_f`。

## 4. 起摆

两套方案，由 `SWING_MODE_SEL` 一处切换（自动决定超时时间）：

| 模式 | `SWING_MODE_SEL` | 原理 | 超时 |
|---|---|---|---|
| **能量泵**（当前） | **0** | `u = −sign(α̇ · cos α)`，反复泵能 | 15 s |
| 甩杆 | 1 | 一次性甩到位再回杆 | 3 s |

能量泵方向由 `SWING_INV = 1` 控制；越摆越小就取反。

> 甩杆是**单次动作，失败不重试** —— 重试会与自然摆荡打架（已撤销）。

捕获条件：连续 `SUCCESS_NEED = 10` 拍满足 `|α| < CATCH_WINDOW(62)` 且 `|α̇| < CATCH_VEL(26)`
→ 切 `S_BALANCE`，此时 `θ_ref` 取当前位置（避免位置项踢动）。

## 5. 按键 / 模式

**两段式确认流程**：先选模式，再确认执行。

| 操作 | 功能 |
|---|---|
| **SW1** | IDLE：起摆 / SWING：取消 / **BALANCE：确认执行所选模式** |
| **SW2** | **仅 BALANCE 且未执行时**轮换模式；**已执行时按 SW2 = 停掉模式**（回纯稳摆，保持平衡） |
| **SW3 / SW4** | 模式 0：目标偏移 ±30°（需 SW1 确认）；曲线模式：调幅值（实时）；模式 4：拍幅 ±10° |
| **SW5** | 硬件复位 |
| **B3_SW1** | 按住捕获当前角度为平衡点（**低有效，开关接 GND**） |
| **B3_SW2 ON** | 编码器方向取反 |

| 模式 | 名称 | LED1~3 |
|---|---|---|
| 0 | 纯稳摆 | 001 |
| 1 | 正弦 | 010 |
| 2 | 三角 | 011 |
| 3 | 线性（单向到终点） | 100 |
| 4 | 四四拍（强 1.0 / 弱 0.4 / 次强 0.7 / 弱 0.4） | 101 |
| 5 | 手轮（摇杆） | 111 |

**LED 约定**：LED1~3 = 模式号 + 1 的二进制，**未执行慢闪 1.5 Hz / 执行中常亮**；
LED4 = 错误闪烁（次数 = `err_code`）。

> ⚠ **BALANCE 状态没有「按键停止平衡」的途径**，只能 SW5 复位或串口 `CMD=2`。

### 手轮（摇杆）模式

起摆进 BALANCE → SW2 轮换到 LED 全亮 → SW1 确认 → 转手轮，摆臂 1:1 跟随 → SW2 退出。

```
wheel_pos ← wheel_pos + 手轮增量             // 死区 WHEEL_DEADBAND = 2 过滤抖动
给定      ← 每 5 ms 最多靠近 wheel_pos WHEEL_RAMP_STEP(2)   // ≈138°/s
给定      不得超前实际位置 WHEEL_LAG_MAX(150)               // ≈52°，防位置环饱和
```

手轮可以转很快，摆臂受「摆杆必须保持直立」限制只能慢慢跟；手轮停下后继续追上，
**最终位置与手轮完全一致**（只是滞后）。

要求 `MOTOR_SEL = 1`（B 通道 = 摆臂）、`USE_ENC2 = 0`（enc1 = 摆臂）、手轮接 XH2。

## 6. 串口协议

### 上报帧（设备 → 上位机，**102 字节 / 20 ms / 115200 8N1**）

| 字节 | 内容 |
|---|---|
| 0–1 | `AA 55` |
| 2–3 | 角度（控制器实际采信的 α-β 滤波值，12-bit） |
| 4–5 | 编码器 1（XH1） |
| 6–7 | 编码器 2（XH2，手轮模式即**手轮**） |
| 8–9 | 总 PWM（有符号，大端） |
| 10 | 低 4 位 = 状态机（0 IDLE / 1 SWING / 2 BALANCE）；bit5 = 手轮模式选中；bit4 = 模式已确认 |
| 11–12 | 原始 ADC 角度；**字节 11 高 4 位 = 预选模式号 0~5** |
| 13–14 | 位置环目标 `pos_target`（有符号） |
| 15–16 | 位置环输出 `pos_pwm`（有符号） |
| 17–18 | 麦克风单频 DFT 幅值 |
| 19–20 | α-β 速度估计（有符号，计数/5ms） |
| **21–98** | **麦克风音频时域 39 点**（16-bit 有符号大端，1953 Hz） |
| 99 | 校验：字节 2~98 异或和 |
| 100–101 | `0D 0A` |

### 下发帧（上位机 → 设备，9 字节）

```
AA 55 01 | addr | dataH | dataL | chk | 0D 0A      chk = 0x01 ^ addr ^ dataH ^ dataL
```

| 地址 | 功能 |
|---|---|
| `0x01`~`0x20` | 运行时可调参数（**共 30 个**，见下表） |
| **`0x10` = CMD** | 1=启动 2=停止 3=软复位 **4=确认模式(arm)** **5=取消模式** |

写入后先进影子寄存器，在下一个控制节拍**原子提交**（避免 P/D 项用到不同增益）。

#### 主要参数

| 地址 | 名称 | 默认 | 地址 | 名称 | 默认 |
|---|---|---|---|---|---|
| `0x01` | `BAL_KP` | 197 | `0x11` | `FLING_STEP` | 341 |
| `0x02` | `BAL_KD` | 1012 | `0x12` | `FLING_KP` | 90 |
| `0x03` | `POS_KP` | 25 | `0x13` | `FLING_KD` | 180 |
| `0x04` | `POS_KD` | 600 | `0x14` | `FLING_BACK` | 80 |
| `0x05` | `POS_KI` | 0 | `0x15` | `FLING_DECEL` | 30 |
| `0x06` | `BAL_KP_CATCH` | 169 | `0x16` | `FLING_WIN` | 15 |
| `0x07` | `BAL_KD_CATCH` | 844 | `0x17` | `FLING_PTICKS` | 60 |
| `0x08` | `POS_KP_CATCH` | 15 | `0x18` | `MIC_FREQ` | 1000 |
| `0x09` | `POS_KD_CATCH` | 500 | `0x19` | `MIC_TH` | 500 |
| `0x0A` | `SWING_GAIN` | 1200 | `0x1A` | `MIC_HOLD` | 20 |
| `0x0B` | `SWING_DAMP` | 20 | `0x1B` | `AB_ALPHA` | 153 |

## 7. 麦克风（MP34DT01）

| 项目 | 值 |
|---|---|
| 时钟 | 3.125 MHz（50 MHz ÷ 16），FPGA 输出 |
| 抽取 | ÷200 → **15.625 kSPS**（3 阶 CIC） |
| 分析 | **512 点单频 DFT**（正交解调），32.8 ms/块，分辨率 **0.24 Hz** |
| 幅值 | `|X| = max + 0.375·min`（免开方，误差 0 ~ −3%），满幅 ≈ 31000 |
| 频率范围 | 1 Hz ~ 7800 Hz |
| 目标频率 | `0x18`（默认 1000 Hz） |
| 点亮阈值 | `0x19`（默认 500） |

换频率只需改 NCO 相位字，不用重算系数 —— 代价只有 2 个乘法器
（相比 512 点完整 FFT 的约 3000 LUT）。

> ⚠ `sin256.vh` 由 `mic_fft.v` 用 `` `include `` 引入，
> **不要加进 `.gprj` 的 FileList**，否则 Gowin 会当独立源文件解析而报语法错。

## 9. 已知限制

1. **时序未收敛**：239 个 setup 违例（TNS −1331 ns，最差 −9.56 ns），
   集中在 `u_ctrl` 的位置环乘法路径。**功能实测可用**，但属于未修的技术债。
2. **DSP 占用 65%**（13/20），再加乘法器会布线困难。
3. **BALANCE 状态无按键停止**：只能复位或串口 `CMD = 2`。
4. **麦克风引脚 `V16` / `U16` 必须按实际板子核对** —— 这两个是本工程未使用的空脚，
   是否引到排针上需要看手册。
5. **角度分辨率偏粗**：新标度下 ADC 1 LSB = **1.348°**（旧 0.240°）。
   不过 250 点平均后静止 σ 只有 0.4 计数，实际可用。
6. 角度标度换过后 `ZHONGZHI_DEF` 失效，**必须重新标定平衡点**。

## 10. 编译与烧写

```bash
cd PIDSYB
gw_sh.exe build_check.tcl
```

GW2A-55 无片内配置 Flash，Programmer 的 Operation **必须选 `External Flash Mode`**，
烧完**重新上电**才会从 Flash 加载。SRAM Program 一断电就丢。
